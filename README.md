# sidescroll-towerdefense

Side Scrolling Tower Defense — hybrid base-management and side-scrolling tactical combat game.

- [Design Document](docs/Tower%20Defense%20Side-Scroller%20-%20Design%20Doc.md)

## Directory Layout

| Path | Purpose |
|---|---|
| `scripts/` | User-facing scripts — install, build, deploy (e.g. `curl ... \| bash`) |
| `dev-tools/` | Developer tooling — Phase 1 CLI tools, future TUI/web UI builders |
| `dev-tools/build_characters/scripts/` | Skill tree SQL generators and validators (`generate.sh`, `validate.sh`, etc.) |
| `assets/samples/` | Reference sample data for unit tests |
